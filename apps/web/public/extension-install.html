Check claims while you read.

This hackathon extension connects to the same Cloudflare app and Neon evidence database as the web client.

  1. Download the extension ZIP and extract it into a folder.
  2. Open chrome://extensions in desktop Chrome and turn on Developer mode.
  3. Choose Load unpacked and select the extracted folder containing manifest.json.
  4. Visit a normal web page, select a factual passage, right-click, and choose Check claims.

The side panel checks the selection automatically. You can also click the extension icon and paste text. Results include evidence and a link to open the same check in the web app.

Chrome internal pages and the Chrome Web Store restrict extension access; use a normal page or the paste fallback.
