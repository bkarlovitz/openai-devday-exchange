# Bundled reference fonts

Inter (400/500/600/700), Space Grotesk (500/600/700), and JetBrains Mono (500/600) are bundled locally so extension and web rendering do not depend on external font requests.

Downloaded from the Google Fonts CSS API and its fonts.gstatic.com asset URLs on 2026-11-21. Each font family is distributed under the SIL Open Font License; see its adjacent `*-OFL.txt`. Sources: https://github.com/google/fonts/tree/main/ofl/inter, https://github.com/google/fonts/tree/main/ofl/spacegrotesk, https://github.com/google/fonts/tree/main/ofl/jetbrainsmono.
